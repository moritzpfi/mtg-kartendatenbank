# Bildquellen der Oberfläche

- Das Magic-Symbol stammt aus der bereitgestellten PNG-Datei. [magic-symbol.png](../web/static/magic-symbol.png)
- Das DHBW-Logo ist eine unveränderte Kopie von `BigData/script/dhbw_logo.png` aus dem Vorlesungsrepository. [dhbw-logo.png](../web/static/dhbw-logo.png)
- Die Kartenrückseite stammt von Scryfall und dient als Ersatzbild im Browser. [Quelle](https://backs.scryfall.io/normal/0/a/0aeebaf5-8c7d-4636-9e82-8c27447861f7.jpg) · [card-back.jpg](../web/static/card-back.jpg)
- Kartenbilder lädt der Browser bei Bedarf von den Wizards-Bildadressen aus der MTG-API. Die Aufbereitung normalisiert diese Adressen auf HTTPS.
